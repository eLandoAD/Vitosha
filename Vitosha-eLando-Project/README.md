# SecureVault — Encrypted File Storage

A web application for storing files securely with end-to-end encryption (E2EE).

## Team
- Person A — Backend (Spring Boot + MySQL)
- Person B — Frontend (Angular)
- Person C — Integration, Docs & Testing

## Tech Stack
- Backend: Java + Spring Boot
- Frontend: Angular
- Database: MySQL

## How to run

### Backend
```bash
cd backend
sudo service mysql start
./mvnw spring-boot:run
```

### Frontend
```bash
cd Vitosha-eLando-Project
npm install -g @angular.cli
ng serve
```

Open the browser at `http://localhost:4200`
